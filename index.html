01

URL and email phishing detection · Live on Streamlit

Decoy

98.8%test accuracy of the logistic-regression meta-learner that stacks the URL models. Every verdict is explained in plain language.
  • URL classifier stacks XGBoost on lexical and domain-trust features (Tranco rank) with a character-level Transformer, combined by a logistic-regression meta-learner.
  • Email classifier combines fine-tuned BERT with XGBoost on 15 engineered features: brand impersonation, manipulation-tactic lexicon and sentiment.
  • Email model went through 8 versions across multiple data sources, fixing data leakage and overfitting, removing near-duplicates, and adding legitimate-urgent samples to cut false positives.
  • A Groq-hosted GPT-OSS-120B layer explains each flagged message in plain language. Model weights live on Hugging Face Hub.

02

Conversational movie recommendation · Live on Streamlit

CineRAG

Groundedthe LLM can only recommend movies it actually retrieved
  • Modular retrieval-augmented pipeline (ingestion, embedding, vector store, memory, enrichment) over the TMDB movie dataset, using all-MiniLM-L6-v2 embeddings and ChromaDB.
  • Corrective RAG loop: the assistant critiques its own retrieval and reformulates the query when results are weak.
  • Follow-ups like "something shorter" work because an LLM rewrites each message into a standalone query before search. Multi-turn memory and taste profiling personalize answers across a session.
  • Names of directors, actors, composers and writers are fuzzy-matched to metadata filters, with rating and vote-count thresholds and a staged fallback when strict filters return nothing.
  • GPT-OSS-120B (via Groq) is limited to structured JSON and to the retrieved candidates, so a movie that was never retrieved cannot appear in the answer. Posters and ratings come live from OMDb.

Six-class retinal disease classification from fundus images · Final year team project · Led a team of 3

RetinXpert

97.2%test accuracy across six retinal classes, with Grad-CAM explanations in a Flask app
  • EfficientNetB3 with three-phase fine-tuning: frozen head, top 100 layers, then all layers, with augmentation, class weighting and label smoothing.
  • Flask app serves the model, returns Grad-CAM heatmaps for explainability and generates PDF diagnostic reports.
  • Data: 2,575 training and 1,450 validation images from multiple sources.
