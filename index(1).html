01

URL and email phishing detection · Live on Streamlit

Decoy

URL + Emailtwo detection layers, each verdict explained in plain language
  • URL classifier stacks XGBoost on lexical and domain-trust features (Tranco rank) with a character-level Transformer.
  • Email classifier combines fine-tuned BERT with XGBoost on 15 engineered features: brand impersonation, manipulation-tactic lexicon and sentiment.
  • Email model went through 8 versions across 5 data sources, fixing data leakage and overfitting, removing near-duplicates, and adding legitimate-urgent samples to cut false positives.
  • A Groq-hosted GPT-OSS-120B layer explains each flagged message in plain language. Weights live on Hugging Face Hub.

02

Conversational movie recommendation · Live on Streamlit

CineRAG

Groundedthe LLM can only recommend movies it actually retrieved
  • Modular retrieval-augmented pipeline (ingestion, vector store, memory, enrichment) over the TMDB movie dataset.
  • Follow-ups like "something shorter" work because an LLM rewrites each message into a standalone query before search.
  • Names of directors, actors, composers and writers are fuzzy-matched to metadata filters, with rating and vote-count thresholds and a staged fallback when strict filters return nothing.
  • GPT-OSS-120B is limited to structured JSON and to the retrieved candidates, so a movie that was never retrieved cannot appear in the answer. Posters and ratings come live from OMDb.
